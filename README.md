this application has been developed to replace excel usage and streamlining routine billing operations for small businesses.
It replaces error-prone, manual spreadsheet workflows by providing centralized client selection, automated calculation logic (subtotals, taxes, and grand totals), strict numerical input validation, and local data persistence to guarantee financial record accuracy and data integrity.

USAGE INSTRUCTION:
Manage Clients: Add or update client details to populate the centralized dropdown selector.

Create Invoice: Select a client from the dropdown and set invoice/due dates using the calendar picker.

Add Items: Enter item descriptions, quantities, and unit prices. Subtotals, taxes, and grand totals will calculate automatically in locked, non-editable fields.

Save Record: Click Save/Generate to store the completed invoice data directly to the local storage directory
